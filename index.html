HTTP PUT vs. HTTP PATCH in REST APIs

Learn the concrete architectural difference between replacing the full representation of a resource (PUT) and applying a partial delta update (PATCH).

HTTP PUT RFC 7231

Complete Resource Replacement

In REST architecture, a PUT request represents replacing the entire editable state of a resource. The client must supply all editable fields.

Where Savoria Uses PUT:

When opening the Edit Dish Modal and submitting changes. All 5 fields (dishName, description, category, price, availability) are sent.

PUT /api/menu/:id (Full Payload)
{
  "dishName": "Pan-Seared Atlantic Salmon",
  "description": "Crispy skin fillet over saffron risotto...",
  "category": "Main",
  "price": 28.50,
  "availability": true
}
HTTP PATCH RFC 5789

Targeted Delta Modification

In REST architecture, a PATCH request modifies only a specific attribute without touching or re-transmitting any other fields.

Where Savoria Uses PATCH:

When clicking the Availability Toggle Switch. The client sends only { "availability": false }, leaving name, price, description, and category untouched.

PATCH /api/menu/:id/availability (Delta Only)
{
  "availability": false
}

Comparison Matrix

Criterion HTTP PUT (Full Update) HTTP PATCH (Partial Update)
Purpose Replaces the complete editable representation Modifies only specific delta attributes
Payload Size Full (all 5 dish fields) Minimal (only availability)
Endpoint PUT /api/menu/:id PATCH /api/menu/:id/availability
Mongoose Method findByIdAndUpdate(id, fullBody) findByIdAndUpdate(id, { $set: { availability } })
Preservation Overwrites with request body Guarantees all other fields preserved as-is

1. Mongoose Schema (`backend/models/MenuItem.js`)

const mongoose = require('mongoose');

const menuItemSchema = new mongoose.Schema(
  {
    dishName: {
      type: String,
      required: [true, 'Dish name is required'],
      trim: true,
      minlength: [2, 'Dish name must be at least 2 characters long'],
      maxlength: [100, 'Dish name cannot exceed 100 characters'],
    },
    description: {
      type: String,
      required: [true, 'Description is required'],
      trim: true,
      minlength: [5, 'Description must be at least 5 characters long'],
      maxlength: [500, 'Description cannot exceed 500 characters'],
    },
    category: {
      type: String,
      required: [true, 'Category is required'],
      enum: {
        values: ['Starter', 'Main', 'Dessert'],
        message: '{VALUE} is not a valid category. Must be Starter, Main, or Dessert',
      },
    },
    price: {
      type: Number,
      required: [true, 'Price is required'],
      min: [0, 'Price must be a non-negative number'],
    },
    availability: {
      type: Boolean,
      default: true,
    },
  },
  {
    timestamps: true,
    versionKey: false,
  }
);

module.exports = mongoose.model('MenuItem', menuItemSchema);

2. PUT vs PATCH Controllers (`backend/controllers/menuController.js`)

// PUT /api/menu/:id — Full Replacement
const updateMenuItem = async (req, res) => {
  const { dishName, description, category, price, availability } = req.body;
  if (!dishName || !description || !category || price === undefined || availability === undefined) {
    return res.status(400).json({ success: false, message: 'All editable fields are required for PUT.' });
  }
  const updated = await MenuItem.findByIdAndUpdate(
    req.params.id,
    { dishName: dishName.trim(), description: description.trim(), category, price, availability: Boolean(availability) },
    { new: true, runValidators: true }
  );
  res.status(200).json({ success: true, data: updated, updateType: 'PUT (Full Replacement)' });
};

// PATCH /api/menu/:id/availability — Partial Update (Availability Only)
const updateItemAvailability = async (req, res) => {
  const { availability } = req.body;
  if (typeof availability !== 'boolean') {
    return res.status(400).json({ success: false, message: '"availability" must be a Boolean.' });
  }
  const updated = await MenuItem.findByIdAndUpdate(
    req.params.id,
    { $set: { availability: availability } },
    { new: true, runValidators: true }
  );
  res.status(200).json({ success: true, data: updated, updateType: 'PATCH (Partial Update)' });
};
